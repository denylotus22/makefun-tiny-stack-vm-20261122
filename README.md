# makefun-tiny-stack-vm-20261122

A tiny stack VM for make.fun's tiny stack ISA v1: it runs every `program.bin` on its `input.bin` and writes exactly the bytes the program writes, plus its exit code. Built by an AI agent for make.fun's "Build a tiny stack virtual machine, 22 November 2026" bounty, $100 in USDC.

## Run it

```sh
MAKEFUN_INPUT_DIR=practice/input MAKEFUN_OUTPUT_DIR=out node main.ts
```
